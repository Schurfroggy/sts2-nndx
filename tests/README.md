# 奶龙布局与播放回归测试

无第三方测试包、无海克斯依赖。C# 控制台链接实际生产脚本，用测试替身隔离游戏与 Godot 原生调用。需要 .NET 10 SDK：

```sh
dotnet run --project tests/sts_nndx.RegressionTests.csproj -- /private/tmp/nndx-layout-cases.json
```

覆盖五个原版角色的边界高度、0.2～3 倍体型、播放中缩放、祖先节点缩放、边界高度回退，以及远端结束、旧回调和部分启动失败后的清理。也覆盖快捷键修饰键冲突语义、原版忽略修饰键与 Godot 组合键的区别、本地输入配置保存 / 清除 / 重启恢复和损坏文件保留。输入控件还验证键盘录制、取消、清除、失焦退出以及拒绝绑定后的显示回退。验证旧配置中的手柄字段会被忽略，并且不会注册手柄动作或显示手柄设置。

多人头像检查包括四张头像替换、其他玩家不受影响、各结束路径恢复、界面重建、旧回调隔离、其他 Mod 改图保护、消息编解码与异常数据、房主转发、重复/乱序/跨房间消息拒绝，以及 120 次切换加 2400 次冷却内连按的资源复用和节点清理。

房间扩展检查包括无身体时的声音/头像播放与自然结束、超时回退、旧音频回调隔离、火堆禁用、建筑师式战斗布局、普通商店与假商人的玩家映射和脚底定位、切房与战斗结束时清理、奖励界面重新触发、多人头像可见性判断及牌库内触发、断线清理，以及跨地图格和章节的旧消息拒绝。

奥斯提检查包括 1:1 尺寸与脚底定位、生命增长缩放、随主人开始/停止、独立死亡清理与音效去重、召唤/复活后接入当前进度、多人归属与消息去重、地图/牌库遮挡、部分失败回退，以及 100 次反复切换后的节点清理。

通用宠物检查包括一名玩家拥有多个宠物时的独立清理、原比例缩放、未知布局回退、中途加入/复活、死亡回调前移除时的音效去重，以及设置开关即时生效、保存失败回退、旧配置迁移和持久化。第三方 Mod 使用自定义渲染或绕开标准宠物注册时，需要另行实测。

手动多人验收（所有客户端安装同一新版；同步协议已升级为 `overlay_v3`）：

1. 两端安装同一新版，开始战斗后检查自己的头像及队友端对应头像一致；停止后都恢复。
2. 多次播放检查 face1/2/3/4，并等待一次自然结束；确认名字、血条与其他玩家头像不变。
3. 两端交替连按快捷键，停止操作后确认头像与角色都能恢复、卡牌仍可正常使用。
4. 播放期间结束战斗或死亡，进入下一场后确认没有头像残留。

5. 在普通事件和宝箱中播放，检查只有声音和同步头像，无旧战斗角色动画；再次按键和自然结束均恢复。
6. 在普通商店、假商人商店、建筑师事件中逐人播放，确认各端替换的是对应玩家，脚底位置正确，停止后还原。
7. 播放时进入下一房间、从事件进入战斗、战斗胜利/失败、退出跑局，确认声音和头像立即恢复；随后在奖励界面可以重新按键播放。
8. 一端打开地图，另一端停留在奖励页面，两端都应能按键播放，且声音、头像一致；各端按身体是否可见显示动画。打开牌库仍能开始/停止，身体动画不应盖住牌库；关闭牌库后继续显示尚未结束的动画。选定下一房间应停止；火堆中按键无效果。
9. 在事件中交替快速按键，并让一位正在播放的玩家断线，确认其余玩家仍可正常操作。
10. 两位死灵契约师分别召唤奥斯提，交替播放，检查每端只替换对应主人的奥斯提；方形动画脚底位置正确，增长生命后仍正确。开始/停止、自然结束、打开地图/牌库及离开房间均无残留。
11. 大笑时让奥斯提死亡，确认只播放一次死亡音效且主人继续大笑；在主人结束前重新召唤，确认奥斯提接入当前播放进度。未大笑时死亡不播放奶龙死亡音效。
12. 在“奶龙大笑 → 召唤物”中关闭“召唤物随主人一起大笑”，检查自己和队友的宠物立即还原，主人继续播放；后续召唤/死亡不再触发宠物效果。重新开启接入当前播放，重启游戏后设置仍保留。
13. 使用通过 AddPet 添加宠物的第三方 Mod，检查多个宠物保持奶龙原比例、各自位置正确；逐个死亡/移除、复活和频繁切换后无残留。多人两端使用同一新版，并分别检查本机开关关闭和开启的效果。

上述命令同时导出生产代码生成的布局参数。用 Godot 4.5.1 的实际节点变换再验证一次：

```sh
godot --headless --path tests/godot --script verify_layout.gd \
  --log-file /private/tmp/nndx-layout-native.log -- /private/tmp/nndx-layout-cases.json
```

检查导出正式包中的四张头像是否能由 Godot 实际加载，以及切换纹理时保持 48×48 UI 尺寸：

```sh
godot --headless --path tests/godot --script verify_portraits.gd \
  --log-file /private/tmp/nndx-portrait-assets-native.log -- "$PWD/artifacts/release/sts_nndx.pck"
```

这些检查不启动游戏、不部署 Mod，也不能代替游戏内的多人目视测试。
