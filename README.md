# 奶龙大笑

《杀戮尖塔 2》Mod，已上架创意工坊。

## 功能

- 可在各个场景中按 **C** 播放奶龙大笑，再按一次停止（火堆除外）
- 有角色身体时替换为奶龙动画；无身体时只播放声音并切换多人头像
- 支持多人同步；大笑时随机切换为四张奶龙头像之一，结束后恢复
- 支持召唤物随主人大笑，可在 Mod 设置中关闭；奥斯提呈方形，其他宠物保持原比例，大笑期间死亡会播放死亡音效
- 可在 Mod 设置的“奶龙大笑 → 按键设置”中修改快捷键，支持组合键和按键冲突检测
- 暂不支持手柄

## 依赖

- 游戏版本 ≥ 0.107.1
- [STS2-RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib) ≥ 0.4.45
